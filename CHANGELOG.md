# Changelog

## 0.1.0

- Initial release.
- `TikTok Shadow Ban Checker` node: check one or more TikTok videos.
- Multi-signal shadow-ban detection with health score, engagement rate,
  viral potential and actionable recommendations per video.
- Options: proxy country, recommendations, batch summary, retries.
- `Apify API` credentials with token test against `/users/me`.
- Calls the `apivault_labs/tiktok-shadow-ban-checker` actor via
  `run-sync-get-dataset-items`.
